# Онега Логистик

Этап 1 из `/root/onega-codex-prompts_1.md`: фундамент, дизайн-система, навигация и подвал. Компания вымышлена. Проект для портфолио Shvetsov Studio.

## Запуск

Node.js 22+, npm. Настройки окружения и внешние сервисы не требуются.

```sh
npm ci
npm run dev
```

Главная: `/`. Витрина компонентов: `/ui`. Все ссылки меню ведут на отдельные заглушки, неизвестные адреса возвращают 404. Расчёт, отслеживание, кабинет и заявки будут реализованы на следующих этапах. Контакты вымышлены, адрес почты использует зарезервированный домен `.example`.

Проверенная production-версия:

```sh
npm run build
npm run start -- --port 3106
```

В текущем окружении соединение HMR у `next dev` не устанавливается, что мешает гидратации. Webpack не устранил ограничение. Для просмотра и приёмки здесь используйте production-команды выше; ошибка не воспроизводится в `next start`.

## Проверки

```sh
npm run lint
npx tsc --noEmit
npm test
npm run build
npx playwright install chromium
# В отдельном терминале: npm run start -- --port 3106
npm run test:browser
```

Можно задать `ONEGA_TEST_URL` и `CHROMIUM_PATH`. Тесты браузера проверяют ширины 360, 390, 768, 1024, 1440, 1920 и 2560, меню, клавиатуру, переходы, порталы, flip списков, якоря, локальность ресурсов и доступность axe. Снимки и машинный отчёт сохраняются в `artifacts/`.

## Структура

- `src/app`: главная, `/ui`, страницы-заглушки и 404.
- `src/components`: общая шапка, подвал, логотип, витрина.
- `src/components/ui`: переиспользуемые компоненты, формы и раскрытие.
- `src/content`: тексты, подписи, навигация и демонстрационные данные.
- `src/lib`: логика разрешения маршрутов и Vitest.
- `src/styles/tokens.css`: единый набор токенов, Tailwind CSS 4 использует CSS-конфигурацию `@theme`.
- `public/brand`: SVG-логотипы на светлом и тёмном фоне, знак. Слово переведено в контуры Inter 700; отдельная загрузка шрифта для SVG не требуется.
- `public/apple-touch-icon.png`: знак для устройств Apple.
- `scripts/export-logo.py`: повторный экспорт SVG из Inter, загруженного сборкой; требует Python fonttools и brotli.

Шрифты загружаются через `next/font/google` во время сборки и раздаются с сайта, CDN в браузере не используется. Оранжевые кнопки имеют тёмный текст для контраста 4.5:1. Третичный серый, оранжевый и зелёный токены не используются как обычный мелкий текст на белом.
