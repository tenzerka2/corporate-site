## Запуск

Node.js 22+, npm. Настройки окружения и внешние сервисы не требуются.

```sh
npm ci
npm run dev
```

Главная: `/`. Калькулятор: `/calculator`. Услуги, направления, отслеживание, тарифы, о компании, контакты, документы, вопросы и правовые страницы работают. Заглушками остаются вакансии, новости, личный кабинет и соцсети. Витрина компонентов: `/ui`. Контакты вымышлены, адрес почты использует зарезервированный домен `.example`.

Проверенная production-версия:

```sh
npm run build
npm run start -- --port 3106
```

В текущем окружении соединение HMR у `next dev` не устанавливается, что мешает гидратации. Webpack не устранил ограничение. Для просмотра и приёмки здесь используйте production-команды выше; ошибка не воспроизводится в `next start`.

## Структура

- `src/app`: главная, `/ui`, страницы-заглушки и 404.
- `src/components`: общая шапка, подвал, логотип, витрина.
- `src/components/ui`: переиспользуемые компоненты, формы и раскрытие.
- `src/content`: тексты, подписи, навигация и демонстрационные данные.
- `src/lib`: логика разрешения маршрутов и Vitest.
- `src/styles/tokens.css`: единый набор токенов, Tailwind CSS 4 использует CSS-конфигурацию `@theme`.
- `public/brand`: SVG-логотипы на светлом и тёмном фоне, знак. Слово переведено в контуры Inter 700; отдельная загрузка шрифта для SVG не требуется.
- `public/apple-touch-icon.png`: знак для устройств Apple.
- `scripts/export-logo.py`: повторный экспорт SVG из Inter, загруженного сборкой; требует Python fonttools и brotli.

Шрифты загружаются через `next/font/google` во время сборки и раздаются с сайта, CDN в браузере не используется. Основная кнопка тёмно-синяя с белым текстом, на тёмных секциях белая; оранжевый остаётся в знаке и подсветке данных на карте (см. AGENTS.md, «Корпоративная палитра»). Третичный серый, оранжевый и зелёный токены не используются как обычный мелкий текст на белом.

## Этап 4

Вторая половина главной: услуги, направления с картой, калькулятор, заявка, условия для постоянных клиентов, вопросы и ответы, финальный блок. Тексты в `src/content/logistics.ts`, компоненты в `src/components/logistics`, стили в `src/styles/logistics.css`.

Тарифы в `src/lib/tariff.ts`, все суммы в копейках:

- расстояние по гаверсинусу × 1,25, внутри одного города 30 км;
- сборный груз: максимум из 1 500 ₽, веса и объёма по зоне. Зоны до 800 / 2 000 / 4 000 км и дальше: 14 / 22 / 32 / 46 ₽ за кг, 3 500 / 5 500 / 8 000 / 11 500 ₽ за м³;
- отдельная машина выбирается по весу и объёму: газель 1,5 т и 9 м³ за 44 ₽/км, 5 т и 30 м³ за 65 ₽/км, 10 т и 50 м³ за 86 ₽/км, фура 20 т и 82 м³ за 110 ₽/км, минимум 100 км;
- забор и доставка от двери по 900 ₽, жёсткая упаковка 12 % от перевозки, каждая строка округляется до рубля;
- срок: день на каждые 600 км, минимум день, сборному грузу ещё день на консолидацию; показывается диапазон из двух дней.

Сроки и цены «от» на карте и в списке направлений считаются той же функцией (`src/lib/routes.ts`, эталонная отправка 100 кг и 0,5 м³), ручных сроков в данных городов больше нет. Клик по направлению или городу на карте подставляет города в калькулятор. Кнопки услуг переключают тип перевозки, ссылки меню `/calculator?service=truck` открывают отдельную страницу с выбранным типом.

Заявка открывается в модальном окне через портал: удержание фокуса, Escape, клик вне, возврат фокуса на кнопку. Маска телефона, проверка ИНН по контрольным цифрам и номер заявки в `src/lib/order.ts`. Заявка никуда не отправляется, это указано в окне.

Карточки услуг вместо рендеров используют крупную цифру на сером фоне: отклонённые изображения не возвращались. Браузерный тест этапа: `tests/home-stage4.spec.ts`, снимки сохраняются в `artifacts/stage-4/`.
