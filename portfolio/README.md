# Материалы кейса «Онега Логистик»

Пересборка: `node scripts/portfolio.mjs` при запущенном `npm run start -- --port 3106`.

- `cover-1920x1080.png`: обложка кейса.
- `onega-walkthrough-1080p.mp4`: 35 секунд, главная, мега-меню, карта, расчёт и заявка.
- `screens/01-home-hero-1440.png`: первый экран.
- `screens/02-home-full-1440.png`: главная целиком.
- `screens/03-mega-menu-1440.png`: мега-меню услуг.
- `screens/04-calculator-result-1440.png`: калькулятор с результатом.
- `screens/05-directions-map-1440.png`: карта направлений с карточкой города.
- `screens/06-service-page-1440.png`: страница услуги.
- `screens/07-tracking-1440.png`: отслеживание груза.
- `screens/08-mobile-hero-390.png`, `screens/09-mobile-calculator-390.png`: мобильная версия.
- `lighthouse/home-mobile.html`: Lighthouse главной, мобильный режим, как опубликовано (noindex).
- `lighthouse/home-mobile-indexed.html`: то же со сборкой `ONEGA_INDEX=1`.

Компания, контакты, цены и документы вымышлены. Демо-проект Shvetsov Studio.
