# Онега

Демо-сайт вымышленной транспортной компании для портфолио Shvetsov Studio. Проект начат заново 06.10.2026; прежняя версия осталась в истории git (коммит 0a7759f).

## Направление

Актуальное направление согласовано 07.10.2026: строгий корпоративный сайт по архивам Oracle, DigitalOcean и Craftcloud. Референсы задают иерархию и структуру, а не копирование чужого бренда.

- Палитра сохранена в `src/app/globals.css`: белый фон, серые секции, тёмный navy на первом экране и в контактах, синие действия.
- Inter 400/500/600. H1 в первом экране 44 px, на телефоне 32 px; H2 36/28 px.
- Общий контейнер 1280 px, боковые отступы 32/16 px. Поля и кнопки 2 px; фотографии и секции прямоугольные.
- Без градиентных масок на фото, плавающих полос статистики и теней на контенте. Тени допустимы у всплывающих меню.
- Первый экран: текст и отдельная фотография. Далее услуги, этапы перевозки, условия работы, калькулятор, отзывы, склады, контакты.
- Числовые факты в обычном тексте; номера только у последовательности действий. Содержание не сокращать ради вёрстки.
- Восемь изображений отредактированы через imagegen: сухие поверхности, обычный свет, естественные следы эксплуатации. Это изображения демо-концепции, а не документальная съёмка реальной компании.
- Иконки только из `src/components/Icon.tsx`, обводкой.
- Обычные поля с рамками, нативные `<select>` и `<dialog>`.
- Нельзя: реальные логотипы клиентов, отзывы с именами людей, анимации появления, градиенты кроме фона первого экрана.

## Архитектура

Многостраничный сайт по схеме Oracle и DigitalOcean: шапка с выпадающими меню «Услуги» и «Компания», хаб услуг, одинаковый шаблон страницы услуги, большой подвал с колонками.

- Карта сайта одна: `src/content/navigation.ts` (меню, подвал, список `routes`). Новая страница добавляется туда и в `pages` в `tests/site.spec.ts`.
- Страница услуги собирается из данных `src/content/services.ts` в `src/app/services/[slug]`: первый экран, цифры, преимущества, условия во вкладках, шаги, кейс клиента, вопросы, другие услуги, карточка менеджера. Новая услуга добавляется только данными.
- Общие блоки в `src/components/ui`: Hero, Stats, Steps, Features, CheckList, Tabs, Faq, Story, ServiceCards, ContactCard, Breadcrumbs. Новую страницу собирать из них, свою вёрстку только для того, чего в них нет.
- Цены на страницах берутся из `src/lib/tariff.ts`, а не пишутся текстом.

## Правила

- Тексты на русском, деловой тон от лица компании. Без длинных тире и канцелярита. Компания и цифры вымышлены, плашка «Демо-проект Shvetsov Studio» обязательна.
- Тексты и данные в `src/content`, логика в `src/lib` с тестами Vitest.
- Каждая ссылка ведёт на существующую страницу или якорь (проверяет `tests/site.spec.ts`).
- Доступность: alt у картинок, подписи у полей, видимый фокус, контраст от 4.5:1, Escape и возврат фокуса у всплывающих слоёв.
- Перед коммитом: `npm run lint`, `npx tsc --noEmit`, `npm test`, `npm run build`, браузерные тесты и скриншоты.
