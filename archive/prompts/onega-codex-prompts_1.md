## Промпт 1. Фундамент, дизайн-система, шапка и подвал

```
Создай с нуля корпоративный сайт вымышленной транспортной компании «Онега Логистик» (короткое название «Онега»): грузоперевозки по России для бизнеса. Это демо-кейс для портфолио веб-студии, поэтому главное: сайт должен выглядеть как у крупной федеральной компании, солидно и аккуратно. В этом шаге делаем фундамент, страницы пока заглушки.

Референс по дизайну и вёрстке: craftcloud3d.com. Берём у него сетку, систему серых, типографику, скругления, тени, структуру блоков и мега-меню. НЕ берём тексты, картинки, иллюстрации, логотипы и фирменный синий цвет.

1. Проект
- Next.js (App Router, последняя стабильная), TypeScript strict, Tailwind CSS, motion (бывший framer-motion), lucide-react для иконок.
- Шрифт Inter через next/font/google с subsets ['latin', 'cyrillic'], начертания 400, 500, 600, 700.
- Деплой будет на Vercel. Никаких внешних CDN, всё локально.
- Тесты: vitest для логики в src/lib.

2. Создай в корне AGENTS.md с правилами проекта (соблюдать во всех следующих шагах):
- Все тексты на русском, деловой спокойный тон, от лица компании «мы». Без длинных тире (вместо них запятая, двоеточие или точка), без канцелярита и штампов вроде «индивидуальный подход», «команда профессионалов», «широкий спектр услуг».
- Компания и все цифры вымышленные. Никаких логотипов реальных компаний, никаких отзывов с именами реальных людей. На сайте есть плашка «Демо-проект Shvetsov Studio».
- Логика (калькулятор, тарифы, сроки) в src/lib и покрыта тестами. Тексты и данные в src/content.
- Адаптив от 360 px до 1920 px, без горизонтального скролла. Доступность: alt у картинок, aria у иконок-кнопок, фокус видно с клавиатуры, контраст текста не ниже 4.5:1.
- После каждого шага: npm run lint, npx tsc --noEmit, npm test, npm run build без ошибок, затем git commit.

3. Дизайн-система (src/styles, tailwind.config)
Цвета:
- Текст основной #0B1F33, текст заголовков #0B2A4A, вторичный #667085, третичный #98A2B3.
- Рамки #D0D5DD, разделители #EAECF0, фон секций #F9FAFB, фон карточек на сером #F2F4F7, белый #FFFFFF.
- Фирменный тёмно-синий #0B2A4A (заголовки, тёмные блоки, подвал). Его светлые оттенки для градиентов: #DCE6F0, #C3D4E6.
- Акцент оранжевый #F26B1D, при наведении #D95A10. Только кнопки расчёта и заявки, иконки галочек и маленькие акценты. Больше нигде.
- Успех #039855, ошибка #D92D20.
Типографика (Inter):
- H1 60/66 600, на мобильном 38/44. H2 раздела 40/48 600, на мобильном 30/36. Подзаголовок первого экрана 26/34 600. H3 карточки 22/30 600. Текст 18/28 и 16/24 400. Подписи 14/20 500.
- Цифры (цены, тонны, сроки) с font-variant-numeric: tabular-nums.
Сетка и формы:
- Контейнер 1172 px, широкий 1472 px, боковые поля 24 px (16 px на мобильном).
- Скругления: кнопки и поля 8 px, карточки 16 px, большой блок первого экрана 40 px, плашки 999 px.
- Тени: в покое 0 1px 3px rgba(16,24,40,.05); при наведении 0 6px 15px -2px rgba(16,24,40,.1), 0 2px 6px 1px rgba(16,24,40,.04); крупные всплывающие 0 20px 25px -5px rgba(16,24,40,.1).
- Отступы между секциями 120 px на десктопе, 72 px на мобильном.
Компоненты (src/components/ui): Container, Section (заголовок, подзаголовок, ссылка справа), Button (primary оранжевая, secondary белая с рамкой, ghost; высота 52 и 44; иконка слева), Badge (белая плашка с тонкой рамкой), Card (рамка #EAECF0, тень в покое, подъём на 2 px и тень при наведении), CheckItem (оранжевая галочка и текст), Stat (крупная цифра и подпись), Input, Select, Textarea, Field с ошибкой, Tabs, Accordion.

4. Логотип
- Нарисуй SVG-логотип «Онега»: слово в Inter 700 с плотным трекингом, перед ним знак: три плавные горизонтальные линии разной длины (вода и дорога одновременно), цвет #0B2A4A, нижняя линия оранжевая. Варианты: на светлом, на тёмном, только знак. Фавикон и apple-touch-icon из знака.

5. Шапка (как у референса по устройству)
- Белая, высота 88 px, тонкая нижняя граница #EAECF0, липкая при скролле, при скролле вниз становится 72 px.
- Слева бургер (открывает полноэкранное меню) и логотип.
- Пункты: «Услуги» со стрелкой (мега-меню), «Почему мы» со стрелкой (выпадающий список), «Направления», «Тарифы».
- Справа: кнопка с рамкой «Рассчитать доставку» с иконкой калькулятора, иконки с подписью снизу: «Отследить», «Кабинет», и телефон 8 800 000-00-00 (вымышленный).
- Мега-меню «Услуги»: белая панель на всю ширину, 4 колонки. В каждой: заголовок-ссылка синим, абзац описания серым, ссылка «Подробнее →», кнопка. Колонки: Сборные грузы, Отдельная машина, Склад и хранение, Доставка на маркетплейсы. Плавное появление 200 мс, закрытие по Esc и клику вне.
- Полноэкранное меню по бургеру: слева кнопки «Рассчитать доставку», «Отследить груз», «Личный кабинет», «Вопросы и помощь»; в центре все разделы списком; справа блок «О компании» с фото (заглушка) и цитатой руководителя (вымышленной, без имени реального человека).
- Мобильная версия: шапка 64 px, бургер, логотип, кнопка «Рассчитать».

6. Подвал (по устройству как у референса, на тёмно-синем #0B2A4A)
- Слева логотип, короткое описание «Грузоперевозки по России для бизнеса», телефон, почта, кнопка «Рассчитать доставку».
- Колонки: Компания (О нас, Вакансии, Новости, Реквизиты), Клиентам (Тарифы, Направления, Документы, Вопросы и ответы, Отследить груз), Мы в сети (Telegram, VK, MAX).

7. Страница /ui с витриной всех компонентов, чтобы я проверил систему. Главная пока с шапкой, заглушкой и подвалом.

Готово, когда: шапка, мега-меню, мобильное меню и подвал работают и выглядят на уровне референса, витрина /ui показывает все компоненты, сборка проходит. Пришли 3 скриншота: шапка с открытым мега-меню, полноэкранное меню, подвал.

```

Левая половина показана как технический чертёж: белые линии каркаса (freestyle или wireframe-модификатор) на прозрачном фоне. Рендер 3840x2400 PNG с прозрачным фоном, для сайта webp 1600 px по ширине.

## Промпт 3. Главная, первая половина

```
Прочитай AGENTS.md и соблюдай его. Собираем первую половину главной страницы. Порядок и устройство блоков как у референса craftcloud3d.com, содержание наше.

- Слева: белая плашка «Грузоперевозки для бизнеса»; H1 «Доставка грузов по России»; подзаголовок «Расчёт онлайн за 2 минуты, подача машины в день заявки».

- Кнопки: оранжевая «Рассчитать стоимость» с иконкой калькулятора (скролл к калькулятору) и белая «Отследить груз».
- Под кнопками строка из трёх иконок с текстом: «Страхование груза включено», «Работаем с НДС и ЭДО», «Отслеживание 24/7».
```
