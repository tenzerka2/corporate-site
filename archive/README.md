# Архив проекта «Онега Логистик»

Снимок от 05.10.2026 по просьбе пользователя сохранить весь результат работы, исходные промпты и точку остановки. Это незавершённый демо-проект, не принятый готовый сайт.

- [Точка остановки и продолжение](STATUS.md).
- [История и уточнения пользователя](HISTORY.md).
- [Исходный файл с пятью промптами](prompts/onega-codex-prompts_1.md), скопирован без изменения содержимого.
- [Восстановление проекта](RESTORE.md).
- [Конфигурация работающего предпросмотра](deployment/onega-preview.service).

В корне проекта сохранены код, конфигурация, lockfile, тесты и скрипты генерации. В `assets/rejected/2026-10-05` сохранена вся отклонённая визуальная серия, включая исходные изображения. В `artifacts` сохранены скриншоты всех этапов, отчёты, патчи, исходники Blender и исходные геоданные. Скриншоты и Blender-файлы, игнорируемые обычным Git, включены в полный архив отдельно.

Полный пакет содержит `project/`, `history.bundle`, `MANIFEST.sha256` и сведения о снимке. Bundle сохраняет все локальные коммиты, поэтому первоначальный вариант кода доступен наряду с последующими исправлениями. `MANIFEST.sha256` перечисляет каждый файл пакета с контрольной суммой.

Не включены устанавливаемые зависимости `node_modules`, сборка `.next`, кэш TypeScript/Python и служебные данные авторизации. Они не являются авторским исходным кодом. Настроек `.env` в проекте на момент снимка не обнаружено. Содержимое соседних проектов не включено.

Точные промпты изображений сохранены только там, где сохранились файлы: `artifacts/stage-2/photo-prompts.json` и `*-prompt.txt`. Полного дословного журнала всех вызовов генерации нет. Он не восстановлен выдуманным текстом. Пользовательские скриншоты Craftcloud и DigitalOcean были присланы в переписке; их исходных файлов в проекте не найдено. `references/craftcloud-access-check.png` показывает блокировку доступа к Craftcloud, это технический снимок, а не присланный дизайн-референс.

Факт упаковки и локальный Git-коммит не подтверждают загрузку на GitHub. Её следует подтверждать отдельно ссылкой на удалённый репозиторий и проверенным коммитом.
