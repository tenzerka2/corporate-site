# Восстановление

Распаковать `onega-archive-2026-10-05.tar.gz`. В полученном каталоге проверить файлы:

```sh
sha256sum -c MANIFEST.sha256
git bundle verify history.bundle
```

`git bundle verify` можно выполнять внутри любого Git-репозитория. Bundle самодостаточный, исходный репозиторий для восстановления не нужен.

Восстановить Git-репозиторий и добавочные материалы, включая игнорируемые скриншоты и Blender-исходники:

```sh
git clone history.bundle onega-restored
cp -a project/. onega-restored/
cd onega-restored
npm ci
npm run build
npm run start -- --hostname 0.0.0.0 --port 3106
```

Проверенное окружение: Node.js 22.22.1, npm 10.9.4. Точные версии зависимостей закреплены в `package-lock.json`. Сборке нужен доступ к источнику шрифтов для `next/font/google`. Внешний backend и секреты для текущего демо не нужны.

Для просмотра первоначального кода после клонирования:

```sh
git show 983cca9:README.md
git log --oneline --all
git diff 983cca9 94727c7 -- src
```

Чтобы открыть первоначальное состояние отдельно, не меняя текущую рабочую копию:

```sh
git worktree add ../onega-original 983cca9
```

В `deployment/onega-preview.service` сохранена конфигурация сервера на момент снимка. При переносе нужно изменить пути и порт под новое окружение. Предпросмотр на исходном сервере может быть выключен позднее и не заменяет архив.

Генераторы в `scripts/` исторические. Они требуют отдельных инструментов, в том числе Blender, Python и библиотек обработки изображений. Это не зависимости запуска сайта. Их запуск может восстановить отклонённую графику в публичном каталоге. Для изучения 3D-сцен используйте сохранённые `artifacts/tractor.blend` и `artifacts/tractor-4k.blend`.
