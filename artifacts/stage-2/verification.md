# Проверка этапа 2

- Линтер, TypeScript, 3 unit-теста, production-сборка: пройдены.
- Главная, UI и страница-заглушка: 360, 390, 768, 1024, 1440, 1920, 2560 px, без горизонтального скролла.
- Галерея: 360, 390, 768, 1024, 1440, 2560 px, все изображения загружены.
- Карта: 18 фокусируемых точек, выбор клавиатурой, поиск в селекте, смена маршрута и срока, нулевые нарушения axe в блоке карты.
- Шапка и меню: Escape, удержание фокуса, переходы, десять циклов открытия, отсутствие оставшихся порталов.
- SVG-контур менее 100 КБ. Все 29 новых WebP проверены на размеры и вес, результаты в asset-validation.json.
- Скриншоты: home-{ширина}.png, hero-1440.png, hero-390.png, map-selected.png, menu-photo.png, visuals-{ширина}.png.
- Проверена публичная ссылка через agent-browser. Предпросмотр включён в автозапуск systemd.

Ограничения: калькулятор и заявки ещё не реализованы, страницы услуг остаются явно помеченными заглушками. Фото вымышленные, мастера 3840 px увеличены из результатов генератора; нативные исходники сохранены. На мобильном для удобного выбора города есть селект с поиском, поскольку точки карты малы.

Финальный полный прогон: 8 из 8 браузерных тестов пройдены за 33.2 с. На промежуточных прогонах обнаружено зависание повторной оптимизации рендеров; готовые сжатые WebP переведены на прямую выдачу. Повторный полный прогон проверяет итоговую production-сборку.
